# Numbers Learning Preset

## Purpose
Create cheerful counting visuals that make numbers click for preschoolers.

## Visual Style
- Big friendly 3D numerals as hero objects
- Exact countable groups of cute objects: three stars, five ducks
- Bright contrasting colors so counts are easy to see
- Objects arranged in clear countable rows or clusters
- Number appears large beside its group, same style every time
- Celebratory accents: confetti, stars, happy bounces on each count

## Storytelling
Count visually, one by one: objects appear or light up in sequence, then the total numeral celebrates. Never show a different count than the number on screen.

## Characters
Use a consistent counting-guide character and identical object designs. Numerals must be perfectly formed and unmistakable.

## Camera
Use calm counting framing: wide enough to see the whole group, slow push-in as the count completes, joyful close-up on the final number.

## Lighting
Use bright even daylight. No shadows hiding objects — every item must be countable at a glance.

## Continuity
Maintain consistent characters, clothing, props, environments, colors, and visual style between scenes.

## Avoid
Wrong object counts, malformed numerals, overlapping uncountable piles, cluttered backgrounds, scary imagery, and rushed pacing.
