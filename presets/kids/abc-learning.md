# ABC Learning Preset

## Purpose
Create clear, joyful alphabet-learning visuals for preschoolers.

## Visual Style
- Giant friendly 3D letters as hero objects in every scene
- One letter paired with one familiar object: A-Apple, B-Ball
- Bright primary colors with high legibility
- Chunky rounded type that feels huggable
- Clean uncluttered backgrounds so the letter always pops
- Playful object animations: bouncing balls, munching apples

## Storytelling
One letter per beat: introduce the letter big, show its object in action, celebrate with a happy reaction. Letter, object, joy — repeat.

## Characters
Use a consistent cheerful guide character plus simple object designs. The letterforms themselves must be perfectly formed and identical each appearance.

## Camera
Use steady teaching framing: centered hero shots of the letter, gentle push-ins on the object, happy reaction close-ups. No dutch angles, no rush.

## Lighting
Use bright classroom daylight with soft shadows. Every letter edge crisp and readable.

## Continuity
Maintain consistent characters, clothing, props, environments, colors, and visual style between scenes.

## Avoid
Lowercase/uppercase mixing without purpose, misspelled or malformed letters, cluttered frames, scary imagery, and fast distracting cuts.
